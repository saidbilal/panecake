# Changelog

What changed in each Panecake release, newest first. After an update the app shows
the section for the new version in its What's New popup, so each one is written
for people using the app.

## 0.4.0

- **Pin projects.** Right-click a project and choose Pin project. It stays in the Pinned area, below the chats you pinned on their own. A chat pinned on its own stays at the top, separate from its project.
- **Sorted by date created.** Chats now list by when they were started, so opening one no longer moves it to the top. To go back, use the sort button above the chat list and choose Last activity.
- **Moved projects.** If you move a project folder and rename its history folder in `~/.claude/projects` to match, its chats now list and open under the new folder instead of the old one.
- **Collapsing a project** also puts its list back to the short length, so it reopens without the extra chats from Show more.

## 0.3.0

- **Pin chats.** Right-click a chat and choose Pin to top. Pinned chats stay above your projects; drag them into the order you want.
- **Sort by date created.** The button above the chat list switches between last activity and date created. Opening a chat counts as activity, so choose date created to keep the list from moving.
- **What's new.** After an update, Panecake shows what changed. Settings can show it again.
